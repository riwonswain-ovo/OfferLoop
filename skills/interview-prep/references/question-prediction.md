# 多证据面试问题预测规范

## 目标

预测不是从题库挑十题，而是判断招聘方最可能通过什么问题验证候选人。先建立小型候选问题池，
再按证据强度、岗位相关性和本轮深度选题。

核心公式：

```text
高相关面经 × JD 核心要求 × 公司/业务当前问题 × 岗位专业方法
× 用户材料中的追问钩子 × 当前轮次与面试性质
→ 本轮预测问题
```

不要求每题命中全部信号，但不能只因“这是常见题”而入选。

## 六类预测信号

| 信号 | 要寻找什么 |
|---|---|
| `E1 面经` | 同公司、业务线、岗位、轮次的原题、追问链和反复深挖点 |
| `E2 JD` | 核心职责、能力、交付、指标、工具和加分项 |
| `E3 公司/业务` | 近期动作、战略重点、业务瓶颈、竞争和关键矛盾 |
| `E4 岗位专业` | 工作链路、常见方法、专业基础、案例、指标和风险 |
| `E5 个人钩子` | 简历/经历中的数字、强动词、转向、空档、复杂职责和证据缺口 |
| `E6 轮次/性质` | 本轮要验证事实、决策、系统判断、动机还是现实条件 |

高相关面经提供真实出题方式，其他信号用于判断其是否仍适用并补足缺口。历史题库只提供问题
形态，不计为目标公司的面经证据。

## 从六个角度生成候选问题

1. `面经复现`：保留与当前 JD 一致的原题和连续追问。
2. `JD 验收`：把每项核心要求改写为招聘方可验证的问题。
3. `业务判断`：把公司当前动作、瓶颈或竞争转成岗位判断题。
4. `专业场景`：沿岗位工作链路生成方法、案例、指标和异常题。
5. `个人深挖`：从用户材料中的可疑、突出或高度相关信息生成 D1–D3 追问。
6. `轮次风险`：补充动机、履历、价值观、规划或系统性判断。

候选池保持最小充分，通常 25–40 道；语义相同的问题合并为一条主问题和追问链。

## 每道候选题的内部记录

```text
问题：
问题类型：面经原题 / 面经归纳 / 资料生成 / 个人材料追问
命中信号：E1–E6
预测依据：
对应 JD：
公司/业务事实：
个人钩子：
本轮深度：D1 / D2 / D3
可回答证据：
事实或置信度风险：
```

“预测依据”必须说明为什么这家公司、这个岗位、这一轮可能问，不能写“高频题”了事。

## 入选和排序规则

正式十五题须满足：

- 至少命中两个有效信号；
- 至少一个来自 E1、E2 或 E3；
- 替换公司名后不能仍然普遍成立；
- 能映射到明确 JD 能力、业务问题或岗位任务；
- 有可靠外部事实和/或用户真实证据支撑回答。

同公司、同业务线、同岗位、同轮次的明确面经原题可直接进入候选前列，但需检查时效和 JD 是否
冲突。Q1–Q3 通常应命中三个以上信号，或属于高度精确的面经原题。

排序依次考虑：

1. 面经匹配精度和追问强度；
2. JD 核心程度；
3. 公司/业务当前重要性；
4. 用户材料被追问的可能性；
5. 轮次与面试性质匹配；
6. 来源时效和答案证据完整度。

## 路由到文档不同位置

- `个人材料追问`：仅当与目标公司、业务领域或岗位强相关时，转成能力迁移题候选；否则保留为
  内部追问提醒，不单独输出经历章节。
- `通用但高风险`：保留为内部提醒；除非完成公司化、业务化或岗位化改写，否则不占正式十五题。
- `公司/业务/岗位场景题`：进入正式十五题候选池。
- `公开资料已经回答的问题`：可转成候选人反问时，必须询问团队实际判断、约束或落地，而非
  重复查百科。

## 十五题组合检查

最终 5 道必练、5 道重点、5 道了解需要共同覆盖：

- 公司或目标业务的当前判断；
- JD 最核心的三至六项能力；
- 岗位专业方法、指标或场景；
- 至少一个真实经历可迁移入口；
- 本轮要求的事实、决策或系统深度。

产品经理及以产品判断为核心的复合岗位还要覆盖行为动机、工作职能、开放业务、产品实战和
费米估算五类；各类题量按公司、JD、轮次与面经证据动态分配，但不得缺类。不为覆盖而机械复述
母题。十五题全部来自同一业务话题、全部来自通用题库或全部只能用同一段经历
回答时，重新选择。

## 失败与降级

- 没有有效面经：以 E2–E6 和适用的五类母题预测，全部标记为资料生成或个人材料追问。
- 公司/业务资料不足：减少确定性表述，不用行业通用题冒充公司题。
- 用户材料不足：保留岗位答题路径并标记个人证据缺口，不生成伪个人答案。
- 轮次未知：优先跨轮高概率题和 D1–D2，明确预测限制。
