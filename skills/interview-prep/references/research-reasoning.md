# 公司、行业与业务研究推理规范

## 用途

在需要回答行业、公司、竞品、业务策略、市场或数据判断时使用。目标不是生成公司百科，而是把
可靠外部事实转化为与目标岗位有关的判断、问题和反问。

## 研究层次

按问题需要选择最小充分范围：

1. `行业层`：市场边界、规模与增速、产业链、驱动因素、政策/技术约束。
2. `竞争层`：主要玩家、集中度、关键成功因素、替代方案和潜在进入者。
3. `公司层`：业务组合、目标客户、价值主张、商业模式、能力与近期动作。
4. `组织场景层`：目标部门/职能承担什么任务，与上下游如何协作。
5. `岗位层`：该岗位需要解决什么问题、交付什么结果、承担什么约束。

研究必须最终落到“这对目标岗位意味着什么”。没有公开组织信息时停留在可证实层级，不用集团
信息冒充部门事实。

## 竞品与替代方案

根据研究目的选择二至四个对象，不贪多：

- 直接竞品：用户、客户、场景和价值主张高度重合；
- 替代方案：以不同方式满足同一需求；
- 潜在进入者：具备相邻能力，可能改变竞争方式；
- 行业标杆：不一定直接竞争，但能提供方法或能力参照。

比较维度从浅到深：

```text
产品/服务与价格
→ 用户或客户路径与运营机制
→ 指标、单位经济性和商业模式
→ 供应链、技术、渠道、品牌或组织能力
→ 对目标公司的机会、约束和岗位含义
```

不能只列功能差异；必须给出比较目的、判断标准和可行动启发。

## 数据与事实交叉验证

遇到关键数字、口径冲突或高影响判断时：

1. 检查发布方、原始来源、发布时间和适用范围。
2. 对齐定义、统计对象、时间范围、币种、地区、含税/不含税等口径。
3. 区分存量与增量、注册与活跃、下单与支付、相关与因果。
4. 优先使用公司披露、监管/统计、标准和专业机构等一手或近一手资料。
5. 用至少一个独立角度验证，例如上下游数量、主要玩家之和、市场份额反推或历史趋势。
6. 无法消除差异时保留区间或并列口径，说明差异来源，不选择看起来最顺眼的数字。

单一社区帖子、营销材料、转载和搜索摘要不能承担关键事实证明。

## 从事实形成判断

内部使用：

```text
问题 → 判断标准 → 已确认事实 → 缺失信息 → 推论 → 岗位行动/风险
```

把内容分为：

- `事实`：来源直接支持；
- `推断`：由事实推导，需说明条件；
- `候选人判断`：面试中的个人观点，可提出验证方式；
- `未知`：证据不足，明确待确认。

不要用用户经历代替外部业务判断，也不要用外部材料替用户补造经历。

## 时间与时效

- 公司动作、组织、人事、产品、价格、指标和竞争格局按当前时间重新验证。
- 历史案例只用于解释机制，标明当时背景，不直接外推到当前。
- 观点材料只提供假设或观察角度，不作为公司事实。
- 题库或课程中的年份数据默认视为待重新检索。

## 输出约束

研究底稿不单独进入成品。只把以下内容用于正式文档：

- 快速复习区中的关键判断和事实边界；
- 十道题中的必要事实、推断条件和岗位回扣；
- 候选人反问的研究依据；
- 信息来源中的实际采用链接。

每个重要判断都应能回答：依据是什么、哪里是推断、为什么与本岗位有关。
