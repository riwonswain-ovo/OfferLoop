# 金字塔式回答与记忆规范

## 内部质量原则

思考时可以从材料归纳，表达时必须自上而下：

1. 先用一句话直接回答；
2. 用二至四个同层支撑点解释；
3. 在支撑点下放事实、数据、机制或例子；
4. 最后补充边界、反思或行动。

同一层必须属于同一类型，例如全部是原因、能力、步骤或判断标准。不要把原因、动作、结果和
例子并列。支撑点按时间、结构、重要性或逻辑递进排序。

生成每段回答前，Agent 内部判断归纳或演绎结构并检查逻辑骨架，但默认不在用户文档中展示
“逻辑类型”“归纳/演绎”或独立的内部分析过程。

## 用户可见记忆结构

用户文档主要展示：

- 一句话结论；
- 3–5 个关键词组成的记忆链；
- 自然口语参考回答；
- 与优先级相匹配的追问或答题路径；
- 仅在必要时出现的特殊风险。

关键词必须能复原完整信息块，不是一串孤立名词。

## 归纳结构

适用于自我介绍、项目复盘、能力证明、为什么适合岗位和多数经历题：

```text
结论 → 同层支撑 A → 同层支撑 B → 同层支撑 C → 回扣
```

支撑点可按能力、过程、重要性或结构分组。组结论必须概括共同说明了什么。

## 演绎结构

适用于方案判断、策略、专业判断和“为什么选择 X”：

```text
结论 → 判断标准/原则 → 本题事实 → 推论或行动
```

口头表达仍然结论先行，不把结论藏到长前提之后。

## 90 秒自我介绍

使用归纳结构：

```text
岗位定位 → 证据 A → 证据 B → 证据 C → 岗位回扣
```

证据块优先按能力分组，每块引用一项最强经历或结果。不同轮次只调整权重，不改变事实：

- 一面：具体动作、专业基础和结果；
- 二面：关键判断、取舍、指标和协作；
- 三面/负责人面：组织、专业或业务影响，系统思考和成长潜力；
- HR 面：经历主线、动机、规划和稳定性。

口语版通常控制在 300–400 个汉字，以自然说完约 90 秒为准。用户文档只展示一句话定位、记忆链、
口语版和预计追问。

## 公司与岗位场景题

回答必须同时完成：

1. 给出直接判断；
2. 用可靠公司、组织、专业或行业事实支撑；
3. 用用户真实经历证明可迁移能力；
4. 回扣目标岗位的关注点或行动。

推荐内部结构：

```text
结论 → 2–4 个同层判断 → 外部事实 → 个人证据 → 岗位回扣
```

外部事实和个人经历不能互相替代。

## 按题型选择内部骨架

- 经历题：结论 → 情境 → 关键行动 → 结果 → 反思；
- 技术题：方案/结论 → 前提 → 实现 → 取舍 → 验证；
- 案例题：结论 → 问题拆解 → 分析 → 建议 → 风险；
- 销售或角色题：目标与对象 → 策略 → 互动/推进 → 结果 → 复盘；
- 设计题：用户问题 → 设计判断 → 方案与迭代 → 效果；
- 研究题：研究问题 → 方法 → 证据 → 结论 → 局限；
- 专业判断题：结论 → 适用原则 → 本题事实 → 判断 → 风险。

题型未命中时选择能使前提、证据和结论连续的最简骨架。

## 按题目优先级控制展示

### 必练

展示一句话结论、记忆链、完整口语回答、可能追问和仅在必要时出现的特殊风险。

### 重点

展示一句话结论、记忆链、精简口语回答、关键追问和仅在必要时出现的特殊风险。

### 了解

展示一句话结论、答题路径、可用个人证据和简洁参考回答。

十道题都有参考答案。优先级只改变展示深度，不允许把低优先级题变成没有个人化内容的空框架。

## 质量检查

- 一句话结论是否真正回答问题；
- 第二层是否只有二至四个同类型支撑点；
- 每个支撑点是否有事实或机制；
- 归纳结构的组结论是否概括全部支撑点；
- 演绎结构的原则、事实和推论是否连续；
- 记忆链能否在不看全文时复原主要逻辑；
- 回答是否保留真实边界；
- 用户文档是否删除了无助于练习的内部分析标签。
