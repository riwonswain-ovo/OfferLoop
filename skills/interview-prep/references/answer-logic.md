# 金字塔式回答与记忆规范

## 内部质量原则

思考时可以从材料归纳，表达时必须自上而下：

1. 先用一句话直接回答；
2. 用二至四个同层支撑点解释；
3. 在支撑点下放事实、数据、机制或例子；
4. 最后补充边界、反思或行动。

同一层必须属于同一类型，例如全部是原因、能力、步骤或判断标准。不要把原因、动作、结果和
例子并列。支撑点按时间、结构、重要性或逻辑递进排序。

生成每段回答前，Agent 内部判断归纳或演绎结构并检查逻辑骨架，但默认不在用户文档中展示
“逻辑类型”“归纳/演绎”或独立的内部分析过程。

## 用户可见记忆结构

用户文档主要展示：

- 一句话结论；
- 3–5 个关键词组成的记忆链；
- 自然口语参考回答；
- 与优先级相匹配的追问或答题路径；
- 仅在必要时出现的特殊风险。

关键词必须能复原完整信息块，不是一串孤立名词。

## 归纳结构

适用于自我介绍、项目复盘、能力证明、为什么适合岗位和多数经历题：

```text
结论 → 同层支撑 A → 同层支撑 B → 同层支撑 C → 回扣
```

支撑点可按能力、过程、重要性或结构分组。组结论必须概括共同说明了什么。

## 演绎结构

适用于方案判断、策略、专业判断和“为什么选择 X”：

```text
结论 → 判断标准/原则 → 本题事实 → 推论或行动
```

口头表达仍然结论先行，不把结论藏到长前提之后。

## 90 秒自我介绍

使用归纳结构：

```text
学校与专业 + 总领句
→ 最差异化契合点 + 关联经历递进 + 岗位迁移
→ 通用方法能力 + 多段经历的共同方法
→ 通用落地能力 + 技术/业务/协作价值
→ 个性化自我评价 + 成长轨迹与内在动机
→ 抗压等评价 + 简洁事实
→ 责任感/结果导向等评价 + 具体工作表现
→ 感谢面试机会 + 希望入职
```

开头只点明最高学历就读学校和专业，随后用总领句引导下文。差异化契合点不是“一项能力配一段
经历”的机械结构，可以把多段相关经历组织成递进证据链，再抽象出与目标岗位的连续性。第一个
通用能力点从多段经历中提取稳定方法；第二个通用能力点补齐落地和协作价值。

自我评价固定为三个最适合岗位的评价点，但不要求三段等长。最具个人辨识度的一点可以通过成长
路径、主动选择和内在动机展开；其余评价用真实事实和行为定义。整段按“结论 → 证据 → 岗位
含义”推进，使用自然口语过渡，不写成六条简历 bullet 的串联。
不同轮次只调整权重，不改变事实：

- 一面：具体动作、专业基础和结果；
- 二面：关键判断、取舍、指标和协作；
- 三面/负责人面：组织、专业或业务影响，系统思考和成长潜力；
- HR 面：经历主线、动机、规划和稳定性。

口语版优先保证差异化证据链和迁移逻辑完整，再压缩通用能力和次要细节。通常控制在自然说完约
90 秒的长度；若六项内容全部需要证据，优先删减项目数字、实现细节和重复结论，不删除“为什么
能迁移到岗位”以及“评价在工作中表现为什么”。用户文档展示口语版和简洁结构提示，不额外
生成经历战斗卡。

## 公司与岗位场景题

回答必须同时完成：

1. 给出直接判断；
2. 用可靠公司、组织、专业或行业事实支撑；
3. 用用户真实经历证明可迁移能力；
4. 回扣目标岗位的关注点或行动。

推荐内部结构：

```text
结论 → 2–4 个同层判断 → 外部事实 → 个人证据 → 岗位回扣
```

外部事实和个人经历不能互相替代。

正式十道题无论属于业务理解、能力迁移、场景解决方案还是投递意图，都必须使用同一金字塔
表达纪律：

```text
一句话结论
→ 二至四个同层支撑点
→ 每个支撑点紧跟对应事实/机制/业务依据/个人证据
→ 岗位回扣、行动或边界
```

不得采用“先列观点 A/B/C，再统一列经历 A/B/C”的分离结构；观点和证据必须逐点相邻。

## 按题型选择内部骨架

- 经历题：结论 → 情境 → 关键行动 → 结果 → 反思；
- 技术题：方案/结论 → 前提 → 实现 → 取舍 → 验证；
- 案例题：结论 → 问题拆解 → 分析 → 建议 → 风险；
- 销售或角色题：目标与对象 → 策略 → 互动/推进 → 结果 → 复盘；
- 设计题：用户问题 → 设计判断 → 方案与迭代 → 效果；
- 研究题：研究问题 → 方法 → 证据 → 结论 → 局限；
- 专业判断题：结论 → 适用原则 → 本题事实 → 判断 → 风险。

题型未命中时选择能使前提、证据和结论连续的最简骨架。

## 按题目优先级控制展示

### 必练

展示一句话结论、记忆链、完整口语回答、可能追问和仅在必要时出现的特殊风险。

### 重点

展示一句话结论、记忆链、精简口语回答、关键追问和仅在必要时出现的特殊风险。

### 了解

展示一句话结论、答题路径、可用个人证据和简洁参考回答。

十道题都有参考答案。优先级只改变展示深度，不允许把低优先级题变成没有个人化内容的空框架。

## 质量检查

- 一句话结论是否真正回答问题；
- 第二层是否只有二至四个同类型支撑点；
- 每个支撑点是否有事实或机制；
- 归纳结构的组结论是否概括全部支撑点；
- 演绎结构的原则、事实和推论是否连续；
- 记忆链能否在不看全文时复原主要逻辑；
- 回答是否保留真实边界；
- 用户文档是否删除了无助于练习的内部分析标签。
