# 现场可见证据重建与失分定位

## 分析顺序

1. 从已确认 ASR 重建问题—回答—追问链。
2. 分离三层：现场明确表达、基于现场的招聘者推断、用户事后补充。
3. 只用前两层评价招聘者当时可能形成的判断；推断必须标注。
4. 选择目标岗位的评价镜头，检查是否出现足够可见证据。
5. 将主要问题定位并回流：
   - 事实缺口 → `experience-deepthink`
   - 简历承诺缺口 → `resume-tailor`
   - 公司/岗位知识缺口 → `interview-prep`
   - 回答组织或承压缺口 → `mock-lab`
   - 可迁移判断或表达承压缺口 → `mock-lab`

## 十岗位评价镜头

| 岗位 | 现场应看见的核心证据 | 常见失分信号 |
|---|---|---|
| AI 产品 | 任务边界、方案选择、评测/失败、价值与成熟度 | 术语代替事实；效果和本人贡献不清 |
| 策略产品 | 目标、信号、规则、实验、护栏、反馈 | 只报指标；没有误伤套利与条件 |
| 商业化产品 | 参与方价值、收入机制、单位经济、体验取舍 | ROI 代结论；经营口径混乱 |
| C 端产品 | 用户场景、行为机制、优先级、验证、副作用 | 功能堆砌；场景过宽；上线当结果 |
| 商业分析 | 决策问题、驱动、洞察、建议、采纳 | 分析止于报告；推断冒充事实 |
| 数据分析 | 口径、拆解、贡献、因果、行动 | 原因穷举；工具清单；因果跳跃 |
| 市场 | 人群、定位、信息、渠道、双时钟归因 | 只讲曝光投放；目标人群模糊 |
| GTM | ICP、切入口、采用、续约/扩张 | 上市清单化；缺购买者与价值兑现 |
| 产品运营 | 生命周期、分层、机制、长期行为 | 活动罗列；短期指标冒充价值 |
| 策略运营 | 信号、规则/资源、执行、博弈、反馈 | 策略无归因、误伤、套利与反事实 |

## 诊断边界

“现场没有证据”不等于候选人不会；“面试官继续追问”也不自动代表负面。必须引用具体原话说明
证据缺在哪一层，不得用事后补充提高招聘倾向。
