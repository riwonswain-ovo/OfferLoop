# OfferLoop 当前任务表达契约

OfferLoop 不再维护跨任务的个人语言画像。需要生成自我介绍、面试逐字稿、参考回答或
其他个人表达时，只使用当前会话或当前任务中用户主动提供或明确授权的样本。

## 来源优先级

1. 用户亲自写作并确认的同类产物；
2. 当前任务中的真实面试 ASR 或自然口语；
3. 用户对本轮 Agent 草稿的实际改写；
4. 当前对话中反复出现的表达特征。

未经用户修改的 Agent 内容不是用户语言样本。不扫描历史画像、无关私人文档或其他对话。

## 生成边界

1. 先校验事实、专业逻辑和岗位要求；
2. 只在不改变事实、指标、责任边界和结论的前提下，调整句子节奏、连接方式和叙事顺序；
3. 样本不足时使用清晰、自然的默认口语，不声称“像用户本人”；
4. 不模仿错字、ASR 错误、无意义口头禅或一时情绪；
5. 不创建、更新或提议更新长期语言画像。
