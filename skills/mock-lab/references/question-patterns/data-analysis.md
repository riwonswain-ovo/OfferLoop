# 数据分析问题模式

本文件提供数据分析岗位的可复用问题家族。根据 JD 选择业务、统计、实验、SQL 或建模深度，不
顺序遍历，也不把术语定义背诵当作完成标准。

## 1. 指标体系

基础问法：为某项业务目标建立指标体系，你会如何开始？

追问：业务目标、北极星指标、过程与护栏、口径、粒度、周期、可行动性、指标冲突和监控。

情境变量：内容、交易、订阅、广告、企业服务、履约和 AI 产品。

## 2. 指标异动

基础问法：某项核心指标突然或持续异常，你会如何定位？

追问阶梯：

1. 如何确认数据和口径没有问题？
2. 异常发生在什么时间、范围和漏斗？
3. 按哪些人群、渠道、地区、版本或供给维度拆解？
4. 假设如何排序，各需要什么证据？
5. 如何处置、验证恢复并持续监控？

可追加条件：同期发布、节假日、渠道变化、埋点迁移或竞争活动。

## 3. A/B 测试

基础问法：如何评估一次产品或策略改动是否有效？

追问：随机化单位、分流、样本量、主指标、护栏、周期、提前停止、污染、显著性、业务意义和
长期效果。

风险信号：只比较实验组和对照组均值，或把统计显著直接等同于值得上线。

## 4. 因果与观察性分析

基础问法：无法随机实验时，如何判断某项动作可能带来了结果变化？

追问：处理与结果、混杂、选择偏差、共同趋势、可用方法、识别假设、稳健性和不能声称的结论。

方法变量：回归、匹配、双重差分、断点、工具变量或其他与 JD 匹配的方法。

## 5. 统计基础

基础问法：解释一个岗位高频统计概念，并说明它如何影响实际决策。

概念变量：抽样、置信区间、假设检验、两类错误、均值与中位数、功效、多重检验。

追问：适用条件、输入输出、错误解释、业务例子和边界，不只追定义。

## 6. 回归与模型

基础问法：面对一个预测或解释任务，你会如何选择模型并评价效果？

追问：目标、基线、特征、数据泄漏、训练验证、评价指标、类别不平衡、稳定性、解释性、部署和
监控。

模型复杂度不得超过 JD 和用户确认的参与深度。

## 7. SQL 与数据处理

基础任务：给出表结构和业务问题，让用户说明查询思路或编写 SQL。

观察：表粒度、Join 关系、空值、重复、时间边界、窗口、性能和结果校验。

追问：如果结果异常大、重复或与看板不一致，如何定位；不只比较标准语法答案。

## 8. 漏斗、留存与分群

基础问法：如何分析转化、留存或流失问题？

追问：人群和事件定义、观察窗口、队列、漏斗顺序、结构变化、分群依据、可行动洞察和验证。

风险信号：只有同比环比和人口属性切分，没有业务机制。

## 9. 分析落地

基础问法：讲一次分析结论与业务方直觉冲突的经历，你如何处理？

追问：口径、证据、替代解释、利益相关方、表达方式、试点、采纳、结果和个人边界。

停止条件：分析发现如何变成真实决策、行动和后续监控已经清楚。
