# 多岗位自适应证据压力

## 使用规则

每次只从用户上一回答选择一个最高风险缺口，并注明内部触发依据。依次选择一种压力动作：

- 证据：所有权、数字口径、时间顺序、来源；
- 机制：为什么有效、替代方案、指标如何连接行为；
- 条件：只改变一个决定性变量，观察结论是否更新；
- 边界：风险、护栏、失败/退出信号、未知。

真实模拟不展示上述分类。不得按本文件顺序遍历。

## 岗位变量

| 岗位 | 高价值压力变量 | 典型风险 |
|---|---|---|
| AI 产品 | 任务成功、失败样本、成本、时延、幻觉、人工兜底、权限、数据质量 | 用技术名词代替产品判断；Demo 当上线 |
| 策略产品 | 目标函数、信号、分层、规则、预算、误伤、套利、竞争反应 | 指标改善无机制；忽略参与方博弈 |
| 商业化产品 | 用户体验、客户 ROI、供给、平台收入、合规、规模弹性 | 单一 ROI 盖章；混用经营口径 |
| C 端产品 | 场景频次、用户成本、关系链、网络效应、留存、副作用 | 功能罗列；上线当结果 |
| 商业分析 | 决策、驱动、假设、情景、敏感性、采纳 | 分析止于报告；事实推断混用 |
| 数据分析 | 口径、结构、漏斗、贡献、因果、实验、外溢 | 穷举原因；相关当因果 |
| 市场 | 人群、定位、品牌阶段、渠道、预算、归因、滞后 | 曝光当价值；短期 ROI 统治一切 |
| GTM | ICP、购买者、渠道、销售周期、采用、续约、扩张 | 上市清单化；试用率当价值兑现 |
| 产品运营 | 生命周期、分层、供给、触达疲劳、留存 | 活动执行代替机制；短期回流当长期价值 |
| 策略运营 | 信号、规则、资源、供需、误伤、套利、反馈 | 事后合理化；没有护栏和反转条件 |

## 判停

一条能力证据链已包含明确结论、事实/专业依据、个人动作或判断、结果/边界，并能承受一次关键
条件变化时停止。连续三次仍无证据，记录风险并换题，不替用户补答案。
