# OfferLoop 首次使用欢迎

## 目标

首次安装时先让用户从三个自然语言入口选择目标；只有用户明确要求时才展开完整十一项能力地图。
不要只列技术名称，也不要在入口介绍前运行线上检查。

## 欢迎顺序

1. 明确十一个 Skill 已安装，但“安装完成”不等于飞书或邮箱已经配置。
2. 先提供三个入口：“找岗位”“管笔面试”“做求职训练”。
3. 说明求职训练可先在 Chat 中开始，保存时再配置飞书；工作台是可选体验。
4. 用户选定入口后，只介绍本次相关 Skill 和隐私边界。
5. 用户要求完整介绍时，再展示以下十一项能力和两个常用闭环。
6. 确认当前目标后进入对应预检；纯 Chat 训练不运行飞书预检。

## 三个首次入口

- 找岗位：使用 `job-collection`，需要配置核心空间和合法招聘信息源。
- 管笔面试：使用 `recruiting-reminder`，需要配置核心空间、邮箱和可选日历。
- 做求职训练：直接选择对应训练 Skill 在 Chat 中开始；需要保存或跨 Skill 复用时再接入飞书。

## 十一个 Skill

### 核心、业务与可选体验

| Skill | 用途 | 可以这样说 |
| --- | --- | --- |
| `offerloop-setup`｜安装与配置 | 初始化知识库、三张 Base、飞书身份和公共配置 | “检查 OfferLoop 是否完成初始化。” |
| `offerloop-workspace`｜求职知识库 | 维护必需的知识库、Base 节点和训练产物 | “检查我的 OfferLoop 知识库是否完整。” |
| `job-collection`｜招聘信息同步 | 从指定来源同步岗位到企业清单 | “同步我的招聘信息源。” |
| `recruiting-reminder`｜笔试面试提醒 | 从招聘邮件识别安排并写入笔面试中心和日历 | “检查最近 7 天的笔试面试邮件，先不要写入。” |
| `offerloop-workbench`｜可选工作台 | 按需部署妙搭可视化工作台和 OAuth | “为我的 OfferLoop 搭建飞书工作台。” |

### 求职训练能力

| Skill | 用途 | 可以这样说 |
| --- | --- | --- |
| `experience-deepthink`｜经历深挖 | 直接从 Chat 中的经历讲述和岗位方向开始，持续维护口述稿、事实边界和故事素材 | “我想讲一段竞赛经历，用来准备财务分析岗，请开始深挖。” |
| `resume-tailor`｜Resume Tailor | 按岗位组合用户选定的真实经历，补齐固定信息并生成一页 PDF 简历 | “根据这个岗位和我选的三段经历，制作一页 PDF 简历。” |
| `pm-sense`｜产品思维训练 | 训练产品与场景题并沉淀 Markdown 产物 | “让我先回答一道产品场景题，再帮我完善。” |
| `interview-prep`｜面试准备 | 结合 JD、简历和素材生成准备文档 | “根据下一场面试和实际投递简历帮我准备。” |
| `mock-lab`｜模拟面试 | 按真实节奏一题一答，结束后统一点评 | “用刚才的准备文档模拟面试。” |
| `talk-review`｜真实面试复盘 | 根据 ASR 还原问答并生成改进方案 | “根据这份 ASR 复盘刚结束的面试。” |

## 常用闭环

- 招聘信息同步 → 真实投递 → 邮件识别 → 笔试面试安排。
- 经历深挖 → Resume Tailor → 面试准备 → 模拟面试 → 真实面试复盘。

业务核心数据进入私有知识库；训练产物只有在用户选择保存时才进入知识库。工作台只做可选聚合展示。

## 隐私说明

> 安装只添加了 Skill；尚未读取你的飞书、邮箱或简历，也没有创建或修改线上数据。接下来先做
> 离线只读检查；创建知识库、Base、工作台或任何业务写入都会另行说明并获得确认。

## 首次选择

确认三个入口后，只问当前想推进哪一项，不询问目标岗位：

1. 初始化或检查核心求职知识库 → `workspace`
2. 找到和同步招聘岗位 → `collection`
3. 整理投递、笔试和面试安排 → `reminder`
4. 深挖经历、制作简历、训练产品思维或准备面试 → `coaching`
5. 额外搭建飞书工作台 → `workbench`
6. 搭建包含工作台的完整 OfferLoop → `full`

第 1、2、3、5、6 项检查必需知识库和三张 Base；第 4 项可先纯 Chat 体验。第 5、6 项可部署
工作台。工作台能力按钮只负责打开 Agent 新任务并预填 Prompt，不在页面内部嵌入 Agent。
