# 笔面试中心安装契约

结构唯一真源为
`../../recruiting-reminder/references/event-schema.md`。安装器、接管流程和验收必须完整读取该文件，
不得在 setup Skill 中维护第二份字段或视图枚举。

## 安装与迁移边界

- 新安装按 v2.0.0 契约创建一张 `笔面试安排` 物理表及受管视图。
- 新安装同时创建内部 `OfferLoop运行状态` 表，并把 table ID 绑定为 `RUNTIME_STATE_TABLE_ID`；
  它承载外部写入/进展联动幂等 claim、失败步骤和每日卡片分页账本，不是第二张笔面试业务表。
- 仓库模板更新不得自动修改现有 Base。
- 真实迁移前只读列出 table/view/field/workflow、记录数和现有枚举，并生成备份与迁移预览。
- 迁移写入、删除 `笔试类型` 与 `笔试子类型`、发布 Runtime 和启用自动化是四个独立授权动作。
- 旧表、旧字段和旧 workflow 在新结构回读与合成验收完成前保持原状；清理还需再次明确授权。
- 历史记录冲突时报告 record ID 与各来源值，不猜测、不覆盖。
