# 岗位能力训练与产物规范

## 常见题型

- 产品设计：为某类用户设计或改进产品。
- 产品策略：增长、留存、商业化、竞争或生态决策。
- AI 产品：真实产品现象、用户行为、价值迁移、竞争优势、平台权力和商业取舍。
- B 端产品：角色链、采购/使用分离、流程、权限和交付。
- C 端产品：场景频次、动机、行为路径和体验取舍。
- 行业分析：价值链、供需、竞争格局和变化驱动。
- 发散场景：信息不全情况下的假设、优先级和验证。

## 题型观察镜头

只在用户完成初答后，按当前答案的最大缺口选择少量观察镜头，不能要求每题
覆盖全部维度：

- AI 产品：能力是否商品化、价值迁移到哪一层、优势是否可积累、谁掌握用户
  关系与控制点、竞争者如何回应、什么条件会推翻判断。任务、模型、评测、
  成本和安全只作为解释这些产品问题的约束。
- 功能产品：用户场景、需求强度、使用路径、方案取舍、交互反馈和采用效果。
- 策略产品：目标、信号识别、干预机制、分层分级、误伤、实验和护栏。
- 商业化：客户价值、付费主体、商业模式、收入效率、体验和生态影响。
- C 端：用户需求、场景、体验链路、增长、留存、分群和长期价值。
- B 端：业务流程、角色权限、组织协作、系统集成、实施成本、推广和交付。

## 点评维度

只选择影响最大的维度推进：

- 问题定义是否准确；
- 原始回答能否拆成单一、可判断的事实、假设、因果和价值判断；
- 分组是否由用户已有判断自下而上产生；
- 同层分支是否使用统一划分标准，是否存在重叠、混层或关键缺口；
- 组结论能否统领下层内容，并共同推出总判断；
- 用户与场景是否具体；
- 目标、约束和成功标准是否明确；
- 信息是否分层而非无序罗列；
- 方案是否与问题一一对应；
- 取舍和优先级是否有依据；
- 风险、反方和失败条件是否被考虑；
- 指标是否能验证核心假设；
- 口语表达是否先结论后论证。

## 答案质量行为锚点

私有市场材料只用于校准以下行为锚点，不按“是否命中材料答案”评分：

| 层级 | 可观察表现 |
|---|---|
| 待形成 | 没有直接回答原题；观点、事实、例子和方案混在一起；只能罗列名词或套用固定框架。 |
| 基本成立 | 有明确判断和若干理由，但分组标准、因果中间步骤、优先级或成立条件仍不清楚。 |
| 有决策价值 | 总判断带条件；理由同层且能共同推出结论；说明关键机制、取舍、反方和最小验证方式。 |
| 可迁移 | 能识别决定性变量及其权重；主动区分事实与推断；给出可证伪信号，并把本题方法迁移到相邻场景。 |

使用锚点时：

1. 引用用户本轮具体表述或结构证据，不只报层级。
2. 同一答案可在不同维度处于不同层级，只反馈最影响结论的二至三个缺口。
3. 市场材料中的高频框架若不能解释当前题目的关键机制，视为无效套用。
4. 用户给出材料未覆盖但逻辑、事实和边界成立的路径，保留为用户独有洞察。
5. 二次作答是否修复关键缺口，比措辞是否接近示范答案更重要。

## 答案就绪检查

质量层级用于诊断表现，`answer-readiness.md` 用于控制流程，两者不能互相
替代。每轮记录当前状态及证据：

- `not_ready`：仍有可能改变结论的决定性缺口，只继续一个针对性追问；
- `ready_for_formal_answer`：判断材料已足够，让用户先独立组织正式答案；
- `ready_for_reference`：用户第一版表达完整，可以公开 Agent 冻结参考；
- `ready_for_finalization`：二次作答修复关键缺口，可以生成最终答案与文档。

不得用层级总分、回答长度、维度个数或对话轮数自动推进。判断依据是未回答
问题是否仍可能翻转结论，以及下一轮追问是否还能改变判断链。

## 卡住与阶段收束

用户说“不知道”时，按以下顺序降低难度：

1. 请用户回到一个具体使用场景；
2. 给出两个不包含答案的判断选项，请其比较；
3. 请其判断一个可观察现象是否成立；
4. 给出少量概念提示，再让用户自行组织结论。

每完成一个关键部分，简要列出已确认判断、仍属假设、尚未回答的问题和下一步。
用户开始混乱时停止扩展，先整理当前因果链。

## 研究规则

外部研究分为两个阶段：

1. 用户初答前完成私下预研，按 `training-lifecycle.md` 生成并冻结教练底稿；
   只告知研究已完成，不展示答案、维度或观点来源。
2. 用户第一次自主总结后公开底稿和来源，并按回答中的新假设补充定向核验；
   新证据另记修订，不能回写首版底稿。

来源优先级为官方资料、监管或统计数据、公司财报、学术或行业研究、可信媒体
和社区观点。按 `xiaohongshu-research.md` 补充登录态小红书研究。记录链接、
发布日期、读取日期和证据性质。信息可能变化时必须联网核验，不能用记忆冒充
最新事实。

## 训练后诊断

用户第一次总结后，结合对话证据诊断视角、逻辑、结构、取舍、边界和表达，
只重点反馈最影响本题的二至三个缺口。每项写明用户原表现、影响和改进方式。
随后生成题型化方法卡，并通过用户二次作答验证是否真正掌握。
