# 岗位能力私有来源库

## 目的与边界

本库登记用户提供、仅限本机个人使用的面试与商业化材料。原文位于
`references/private-sources/`，被 Git 忽略，不得提交、上传、公开传播或长篇
写入训练产物。

只把材料用于：

- 识别题型和面试官可能考察的判断任务；
- 对照同题的多种回答路径；
- 发现常见套话、因果跳跃、混层和边界缺失；
- 校准 `coaching-rubric.md` 的行为锚点；
- 为商业化题补充术语、机制和可能的追问方向。

不得把材料用于：

- 代替用户独立初答；
- 生成或换壳每日题单；
- 证明公司当前动作、行业数据或内部动机；
- 把示范答案当作唯一标准；
- 复制原文形成可发布内容。

私有目录不存在时直接跳过本库，不得因此中断训练。

## 已沉淀能力

运行时先使用以下抽象成果，避免反复依赖原文：

- `question-archetypes.md`：从业务题、开放题和 case 中提炼八类判断任务、
  核心因果链、非诱导追问和常见失误。
- `question-mining-and-selection.md`：从成熟题目的共同结构中提炼八种问题
  形状、主问题与延伸问题的层级边界、候选问题卡、七项硬门槛和用户难度
  适配，用于决定“什么值得问、第一问应该问到哪一层”。
- `commercialization-reasoning.md`：从商业化材料中提炼经营系统、价值流、
  变现模式、单位经济、体验取舍、数据异动与从零到一决策顺序。
- `answer-diagnosis.md`：从题库中质量参差的多版本答案反向提炼稳定坏味道、
  影响、追问和修复证据。
- `answer-readiness.md`：把优质回答的共同闭环转成七项硬门槛、题型附加条件、
  停止追问测试和四级生成权限，用于决定“什么时候已经问够”。

只有要检查相似题的原始语境、寻找其他合理路径或确认某个材料观点时，才进入
`private-sources/`。抽象成果与原文冲突时，回到当前题目的公开事实、用户逻辑
和决策目标，不以原文为准。

## 检索协议

1. 先判断本题属于产品功能、策略、商业化、AI、B/C 端、行业分析、数据
   异动或发散场景中的哪一类。
2. 只选择一至两份最相关材料。优先搜索题目中的产品名、行为、机制和核心
   矛盾，不搜索预设答案。
3. 先查看命中行和相邻标题，再读取完整题目或小节；一次只加载一个相关
   区间，避免把无关答案带入上下文。
4. 从片段中只记录：
   - 面试官可能要求做出的判断；
   - 一至三条可迁移的推理动作；
   - 常见失误或反例；
   - 需要公开核验的事实与数据；
   - 与当前教练底稿不同的合理路径。
5. 私有材料记录与公开事实证据分开。不得把本机路径、购买信息、联系方式
   或版权声明写进正式训练文档。

可使用以下只读检索方式，其中 `<关键词>` 必须来自当前题目：

```bash
rg -n -C 4 '<关键词>' references/private-sources/<文件名>
rg -n '^#{1,4} ' references/private-sources/<文件名>
sed -n '<起始行>,<结束行>p' references/private-sources/<文件名>
```

建议关键词组：

- 产品与策略：`产品名|功能名|用户行为|竞争|增长|留存|优先级|需求分析`
- 商业化：`商业模式|变现|IAA|IAP|广告|竞价|ROI|LTV|付费|佣金`
- 数据分析：`指标异动|漏斗|归因|AB test|留存|转化率|供给|需求`
- AI 产品：`AI 产品|模型|评测|幻觉|人机协作|成本|延迟|安全`
