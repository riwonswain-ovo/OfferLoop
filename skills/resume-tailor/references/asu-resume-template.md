# ASu 同款单栏高密度技术简历模板

## 适用场景

用于 `/asu-resume` 复刻参考图中的中文技术简历，适合应届生、实习生和 AI/Agent/LLM/前端工程方向候选人。模板强调“身份定位 → 公开背书 → 项目全景 → 个人职责 → 技术证据”，不把经历写成无法追问的宣传文案。

## 页面结构

1. **顶部信息区**：姓名、电话、邮箱、微信/主页、年龄或身份、目标岗位、GitHub/开源身份、学校和毕业时间；最右侧预留证件照位置。
2. **经历分区**：用蓝色粗体标题和细蓝线分隔，默认顺序为“实习经历 → 项目经历 → 校园经历 → 技能与其他”；内容不足时不强行分页留白。
3. **公司条**：浅灰圆角背景，左侧放公司或平台 Logo，中间写团队/业务/岗位，右侧写时间与公开链接。
4. **项目标题**：蓝色加粗，必要时加中英文项目名、仓库链接或产品链接。
5. **项目要点**：按“背景/目标 → 我的职责 → 关键技术动作 → 结果证据”排列；每个项目 2—5 条，技术细节用缩进子弹点展开。
6. **分页**：始终使用一个连续 `.sheet`，交由浏览器按 A4 自然分页；不新建“续页”容器或重复模块标题。长项目正文可在行间自然跨页，并至少保留两行页尾与两行页首；公司条与紧随的首条内容不孤立，避免前页大面积留白。

## 对齐栅格

- 页面左右外边距必须相等，默认均为 7 mm；正文可用宽度优先，不得再叠加整列空白缩进。
- 模块标题文字、项目标题、正文首行和正文续行直接从页面内容边界开始，并共用同一横坐标。
- Logo 只占公司条内部的独立图标列；它可以推动同一公司条内的名称，但不得推动下方项目标题或正文。
- 教育经历的校徽与公司 Logo 共用 22 px 图标列，校名、专业和日期不因校徽宽高而改变起点。正方形或圆形校徽使用 `object-fit: contain`；宽版组合标志只在固定视窗中显示校徽部分，但必须保留完整外环和至少 1 px 内边距。
- 没有可核验 Logo 的教育或经历条仍保留同宽图标列，使用内置教育图标或空列，保证名称起点一致。
- 日期占用最右固定列并右对齐；字号与左侧公司 / 学校名称一致，默认均为 11.2 pt；同一层级日期的右边界误差不超过 1 px。
- 教育条中学校名与专业 / 学历之间的分隔点只保留约 4 px 左间距；不用大间距、全角空格或多个不间断空格做布局。
- 正文不使用浏览器默认 `ul/li` 缩进。项目符号不得推动正文；续行必须回到首行文字起点。
- 二级与三级信息用标签字重、段间距和语义顺序区分，不再叠加横向缩进。
- 页面主体左右边界误差不超过 1 px，同级元素左边界误差不超过 1 px；发现错位时修改共享页边距或栅格变量，不逐条添加补偿 margin。

## 视觉参数

- 纸张：A4，四边页边距固定为 7 mm；正文默认 10.5 pt、行距 1.32，相邻正文段落间距 2 px。
- 姓名：20—24 pt，黑色加粗；顶部定位和联系信息紧凑排列。
- 分区标题：12.5–14 pt，默认 13.5 pt，使用蓝色 `#2458B8`，下方约 1–1.5 px 蓝线；标题高度接近正文的 1.25–1.35 倍。
- 项目标题：11—13 pt，蓝色加粗；正文黑色，关键词可加粗但不要整段加粗。项目标题与正文共用内容轨道。
- 公司条：背景 `#F3F4F6`，圆角 6 px；Logo 建议 22—28 px，保持等比，不拉伸。
- 链接：蓝色，并在可见文字中保留规范化 URL、DOI 或可识别的“域名/关键路径”；打印后不能只剩“网站”“PAPER”“CODE”等标签。长地址去掉无关追踪参数后允许换行，不能把无法公开验证的内容写成背书。
- 字体：中文统一优先使用 `SimHei`、`黑体`、`Microsoft YaHei` 等黑体字体；英文使用 `Times New Roman` 风格，并准备通用回退字体。
- 个人信息图标：电话、邮箱、微信、身份、教育和 Star 图标统一使用 `../../assets/icons/` 中的 SVG，不使用 Emoji；品牌 Logo 继续使用 `../../assets/logos/`。
- 页面模式：HTML 工具栏提供 `A4 分页` 和 `A4 长页（不限高度）` 两种模式；分页模式显示 A4 纸张边界，长页模式保持 A4 宽度并连续向下编辑。
- 编辑工具：选中文字后可在同一工具栏修改字体、字号、文字颜色和加粗，使用撤回/前进修正编辑，并由浏览器本地自动保存；同时可使用打印按钮导出 PDF。
- 证件照：右上角使用 22×28 mm 照片框，底边与左侧最后一行个人信息对齐，避免照片额外撑高顶部信息区；支持点击选择或替换本地图片。虚线边框只在空占位状态显示，打印已上传照片时边框为透明。
- 页面密度：按 [`/resume` 页面平衡规则](../../resume/references/page-balance-qa.md) 测量每张 `.sheet`；优先通过内容重排和结构合并消除大面积空白，不靠缩小到难读或添加装饰填充。

## Logo 资源库

Logo 文件统一放在 `../../assets/logos/`，文件名使用小写英文或品牌英文名，和简历内容解耦。获取 AI、模型、平台或公司 Logo 时，优先遵循 [LobeHub Icons 技能说明](https://lobehub.com/icons/skill.md)，使用 `@lobehub/icons` 或 `@lobehub/icons-static-svg` 的 SVG/CDN 资源。

学校 Logo 不从公司 / App 目录猜测。优先使用用户提供素材；缺失时查找学校官网的学校标识、视觉识别系统或章程页，核对校名后保存原图和来源到当前简历 `assets/`。不使用带水印素材、搜索结果缩略图或第三方重绘图。

不内置或自动抓取 App Store / iTunes Search API 返回的 App 图标。公司、产品与学校 Logo 只使用用户
明确提供的素材，或能够确认允许当前用途和再分发方式的官方素材；无法确认时使用无 Logo 的文字条。

## 内容规则

- 内容来源、实习/项目差异、补充素材发现与 Markdown 确认遵循 `resume-content-methodology.md`；本文件只
  约束这些内容进入 ASu 模板后的视觉表达。
- 保留正式职位、公司、时间和教育背景，不用模板制造更高职级。
- 每个“Owner、主导、架构、0→1、核心作者”都要能由职责、提交、上线或评审证据支撑。
- 项目总调用量、用户数、Star/Fork 等指标要标明口径；项目数据不能自动算成个人数据。
- 先写个人贡献，再写技术栈；技术名词后面必须有动作或结果。
- 个人技能与自我评价固定合并为一个分区：技能只写有事实依据的工具、方法、语言或证书；评价使用
  具体经历或工作行为支撑，不拆成两个分区，也不使用空泛形容词填充版面。
- 不确定的信息用 `【待补：指标/职责/链接】` 标记，成稿前集中让用户核对。

## 输出与校验

默认生成真正可编辑的 HTML，而不是整页截图。生成后检查：

- A4打印预览是否为预期页数；
- 联系方式、链接和中文字体是否可复制；
- Logo 是否清晰、等比、没有挤压；
- 公司条、项目标题和子弹点是否被分页拆开；
- 页尾是否有空白过大、文字溢出或下一页孤立标题。
- 单页是否形成完整闭环；双页的第一页是否先填实、末页空白是否能通过重排消除，并在交付说明中记录各页占用比例。
