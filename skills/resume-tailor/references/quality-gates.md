# Resume Tailor PDF 简历质量门禁

## 红线

任一失败都必须修正后重新渲染：

- PDF 不是恰好一页；
- 姓名、公司/组织、岗位、日期、数字与来源材料不一致；
- 出现占位符、示例人物、空区块或“暂无”；
- 字号低于 10pt；
- 中文乱码、文字重叠、内容被裁切或项目符号错位；
- 把团队结果写成个人独立结果；
- 写入用户未确认的技能、奖项、证书或自我评价；
- PDF 与用于视觉检查的 PNG 不是同一内容源。

## 内容检查

- 目标岗位和 JD 版本明确；
- 用户明确选择了最终经历、顺序和主打角度；
- 每项核心能力至少有一条真实证据，缺失项已如实标记而非补造；
- 每条 bullet 能回答“做了什么、如何做、产生什么结果或交付”中的至少两项；
- 教育、荣誉、技能、自我评价均在用户确认的展示范围内；
- 联系方式只有一组，且没有不必要的敏感信息。

目标岗位命中 AI 产品经理专项时，同时检查：

- 每个 Agent、RAG、微调、MCP、模型训练等技术词都能在用户选择的经历材料中定位；
- Demo、PoC、MVP、试点和生产运行的用词与真实阶段一致；
- 模型/系统、产品、业务和安全指标没有互相替代，数字证明范围清楚；
- 团队算法、工程或业务成果没有改写为候选人个人实现；
- 没有为了匹配 JD 添加未使用的模型、平台、框架或方法；
- 没有从课程案例、参考答案或行业示例补入项目数字。

## 视觉检查

查看整页 PNG，逐项检查：

- A4 边界完整，四周留白平衡；
- 页眉没有挤压或异常换行；
- 区块标题、经历标题和日期层级清晰；
- 日期右对齐，长组织名不会压住日期；
- 中文字体正常，英文与数字可读；
- 每条 bullet 不出现孤立的一两个字换行；
- 底部正文与纸张底边通常保留 10–20 mm。

`scripts/check_resume_density.py` 只提供纵向留白提示，不能替代目视检查。

## 事实对照

生成后从 HTML/PDF 抽取或人工逐项核对：

1. 所有日期；
2. 所有数字和百分比；
3. 所有组织、项目、角色和奖项名称；
4. 所有工具、语言和证书；
5. 每段经历的个人贡献与团队成果归属。

## 降级交付

- 缺浏览器：只交付 HTML 草稿，说明未生成 PDF。
- PDF 已生成但无 PNG：交付 PDF时说明视觉检查未完成。
- 内容不足：交付诚实的较短版，并列出最值得继续深挖的 1–3 个事实缺口。
- 关键字段缺失：不得保留占位符；删除对应字段并在交付说明中列出。
