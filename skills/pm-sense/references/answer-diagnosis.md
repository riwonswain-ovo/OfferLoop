# 产品回答诊断与非诱导追问

本文件提炼自大量同题多版本回答。题库中的答案质量参差，价值主要在于暴露
稳定坏味道。用户初答后，只选择最影响结论的一项推进；修复后再判断下一项。

## 导航

- 诊断顺序
- 任务与结构：答非所问、无判断、无机制、方案先行
- 逻辑与决策：事后合理化、比较漂移、指标代结论、抽象平衡
- 证据与边界：事实动机混用、单方视角、阶段缺失
- 专项问题：AI 清单化、异动穷举、估算伪精确
- 追问质量检查

## 诊断顺序

1. 先检查是否回答了原题要求的判断任务。
2. 再检查总判断能否由下层理由推出。
3. 再检查决定性因果、比较基准、权重和边界。
4. 最后才处理表达精炼、术语和例子。

不要因为答案覆盖维度少就先补维度。一个闭合的关键因果链，通常比五个无权重
栏目更有价值。

## 一、答非所问

- **信号**：题目问“该不该做”，回答只解释“为什么别人做”；题目问原因，回答直接给方案。
- **影响**：缺少决策结论，后续内容再丰富也无法支撑原题。
- **追问**：“如果现在必须做出选择，你的结论是什么？这个结论服务哪项决策？”
- **修复证据**：首句直接回答原题，并给出必要条件。

## 二、罗列但没有判断

- **信号**：连续列用户、平台、商家、竞争、风险，每点都正确，却没有主次。
- **影响**：分类替代了思考，不能说明哪个因素决定结论。
- **追问**：“删掉其中一项后，哪一项仍最能改变你的结论？为什么？”
- **修复证据**：明确决定性变量、权重或优先级。

## 三、套框架但没有机制

- **信号**：频繁出现“提升体验、增强粘性、形成闭环、精细化运营”，无法说明中间发生了什么。
- **影响**：上层词语不能被验证，也不能指导产品决策。
- **追问**：“这个动作先改变谁的什么行为，随后哪项指标才会变化？”
- **修复证据**：补出动作 → 行为 → 结果的中间链。

## 四、方案先于问题

- **信号**：产品设计题一开始就给功能；商业化题直接加广告、会员或补贴。
- **影响**：方案可能解决次要问题，且无法解释优先级。
- **追问**：“先不谈方案，当前最需要改变的用户行为或业务结果是什么？”
- **修复证据**：先定义场景、障碍、目标和成功标准，再选择方案。

## 五、事后合理化

- **信号**：看到成功结果后，为现有动作补出一套确定性原因；把同时发生当作因果。
- **影响**：忽略时机、执行、外部变化和幸存者偏差，方法无法迁移。
- **追问**：“当时还有什么合理解释？如果这个动作没做，结果一定不会发生吗？”
- **修复证据**：保留替代解释，并提出可区分解释的证据。

## 六、比较标准漂移

- **信号**：比较 A 时讲用户，比较 B 时讲功能，再用收入下结论。
- **影响**：分支不可比，优势只是各说各话。
- **追问**：“你想回答的共同问题是什么？能否用同一标准重排双方证据？”
- **修复证据**：统一基准，并指出哪项差异最能解释结果。

## 七、指标代替结论

- **信号**：“ROI 高所以做”“CTR 上升所以成功”“GMV 大所以模式好”。
- **影响**：指标只描述局部结果，可能忽略回收周期、规模、利润、长期伤害和机会成本。
- **追问**：“这个指标回答了哪一部分问题？还缺哪个条件才能支持你的决策？”
- **修复证据**：指标回到业务阶段和因果链中，并加入护栏或反事实。

## 八、抽象谈平衡

- **信号**：“在用户体验与商业化之间找到平衡点”，没有对象、场景或阈值。
- **影响**：回避了真实取舍，无法执行和验证。
- **追问**：“对哪类用户、在哪个节点、牺牲什么换取什么？红线是什么？”
- **修复证据**：给出分群、触点、价值交换、频率和长期护栏。

## 九、事实、观点和动机混在一起

- **信号**：把媒体评论、作者观点或产品结果写成公司真实意图。
- **影响**：证据强度被夸大，容易形成漂亮但不可验证的故事。
- **追问**：“哪部分是事实，哪部分是你的解释？什么证据会推翻这项解释？”
- **修复证据**：分别标记事实、假设和推断，并保留限定语。

## 十、只看一个参与方

- **信号**：平台策略只分析平台收入；补贴只分析用户增长；规则只分析效率。
- **影响**：忽略成本转移、利益博弈和参与方反应，落地时容易失效。
- **追问**：“这个规则改变后，谁的收益、成本或议价权变化最大？他会如何应对？”
- **修复证据**：补出最关键的第二参与方及其行为反馈，不要求列全体利益相关方。

## 十一、没有业务阶段

- **信号**：对冷启动、增长、成熟和收缩期给出同一套策略。
- **影响**：目标和资源约束错位，正确动作可能出现在错误时间。
- **追问**：“当前阶段最需要验证的是需求、规模、利润还是现金流？”
- **修复证据**：策略与阶段目标一致，并说明下一阶段切换条件。

## 十二、AI 能力清单化

- **信号**：只列生成、总结、推荐、客服或 Agent 工具，没有解释这些能力会
  改变谁的行为、产品形态、价值归属或竞争结果。
- **影响**：能力清单无法回答产品为什么这样做，也无法判断相同能力普及后
  谁仍有优势。
- **追问**：“如果这些能力明天成为所有产品的标配，你认为用户为什么仍会
  选择其中一个？哪个行为或控制点真正发生了变化？”
- **修复证据**：能力只作为前提，答案补出产品动作 → 用户/参与方行为 →
  价值迁移或竞争结果的机制。

## 十三、AI 实施知识替代产品判断

- **信号**：题目问 Agent 护城河、产品差异或平台动作，回答转去讲 RAG、
  Prompt、评测集、工具接入或系统架构怎么搭。
- **影响**：技术方案没有回答价值迁移、竞争优势和产品胜负，无法解释为什么
  同样拥有技术的产品会产生不同结果。
- **追问**：“先假设竞争者也能获得相同技术，你的结论还成立吗？剩下哪个
  稀缺变量最能决定用户选择或价值归属？”
- **修复证据**：把技术事实降为约束，补出用户行为、任务入口、工作流、信任、
  分发、数据复利、成本或生态中的决定性机制。

## 十四、异动原因穷举

- **信号**：指标下降后立即列产品、用户、渠道、竞品、季节等十几种可能。
- **影响**：没有排查顺序、贡献度和验证方法，无法收敛行动。
- **追问**：“先排除数据问题后，你会怎样横向定位主要人群，再纵向定位漏斗环节？”
- **修复证据**：形成口径 → 分层 → 漏斗 → 贡献 → 验证的路径。

## 十五、研究或估算追求伪精确

- **信号**：给出精确市场数字，却没有定义、口径、假设或交叉验证。
- **影响**：精确掩盖了不确定性，数字无法支持决策。
- **追问**：“哪个假设最敏感？换一条独立估算路径是否仍在同一量级？”
- **修复证据**：给出范围、关键假设、敏感性和至少一种校验。

## 追问质量检查

每次追问前确认：

- 是否引用了用户已经说出的内容；
- 是否只解决一个最关键缺口；
- 是否询问机制、权重、反例或验证，而非暗示参考答案；
- 用户回答后是否能够明确判断该缺口已修复或仍未修复；
- 是否给用户留下形成不同于教练底稿结论的空间。
