# 产品 Sense 判断任务谱系

本文件提炼自用户提供的业务分析、商业化和产品面试材料。它用于私下识别题目
真正要求完成的判断任务，不是初答前展示给用户的答题模板。一个题目可能跨两类，
只选对结论最关键的主任务，其他任务作为支撑。

## 导航

- 使用协议
- 机制解释、对比与定位、业务与策略判断
- 产品或场景设计、优先级与取舍
- 数据异动与归因、行业研究与市场估算
- AI 产品判断
- 题型化方法卡

## 使用协议

1. 先用一句话写清：`这道题要求判断什么，以及判断将支持什么决策`。
2. 再选择一种主推理关系：因果、比较、结构分解、时间、重要性或估算。
3. 用本文件检查教练底稿和用户答案的决定性缺口；不要要求用户覆盖全部镜头。
4. 追问用户已经提到但尚未闭合的机制，不把下列推理链直接念给用户。

## 一、机制解释：为什么这样设计

常见题干是“为什么有这个功能、规则或限制”“为什么 A 有而 B 没有”。

- **判断任务**：解释一个设计如何改变行为，并说明它服务的目标与代价。
- **核心链**：场景或约束 → 产品动作 → 用户/供给行为变化 → 系统结果 → 副作用与边界。
- **决定性检查**：用户说的是公司动机猜测，还是可观察的行为机制？
- **高价值追问**：
  - “你说它能提升体验，具体改变了用户路径中的哪一步？”
  - “如果移除这个设计，最先恶化的可观察行为是什么？”
  - “哪些用户或场景会因为这个机制受损？”
- **常见失误**：用“提升体验、增加粘性、促进商业化”代替中间机制；从结果倒推唯一动机。

## 二、对比与定位：差异从哪里长出来

常见题干是“比较 A 和 B”“为什么两款相似产品采取不同方案”。

- **判断任务**：在统一比较基准下，找出造成关键结果差异的决定性变量。
- **核心链**：共同需求或市场 → 定位/用户任务差异 → 能力与约束差异 → 产品机制差异 → 结果与适用边界。
- **决定性检查**：每一列是否都在回答同一个比较问题，还是功能、用户、收入各说各话？
- **高价值追问**：
  - “你现在比较它们的统一标准是什么？”
  - “这些差异里，哪一个最能解释最终结果，为什么？”
  - “如果交换流量、供给或履约能力，结论会不会变化？”
- **常见失误**：功能清单式对比；把规模描述当成竞争优势；忽略业务阶段和能力形成路径。

## 三、业务与策略判断：值不值得做、怎么活得更好

常见题干是“为什么进入某赛道”“该不该跟进”“未来如何发展”。

- **判断任务**：在目标、阶段和约束下选择方向，而不是证明所有方向都有价值。
- **核心链**：市场与阶段 → 用户问题和价值 → 获客/留存/变现机制 → 必要能力与资源 → 经济性和可持续性 → 选择与退出条件。
- **决定性检查**：答案是在讲一个“好故事”，还是能够回答为什么现在做、凭什么做成、何时停止？
- **高价值追问**：
  - “这项动作在当前阶段优先解决什么问题？”
  - “它依赖哪项现有能力？哪项能力必须新建？”
  - “什么信号说明方向正确但执行有问题，什么信号说明方向本身错误？”
- **常见失误**：先抄竞品动作再补理由；只谈市场空间，不谈切入点和单位经济；只说必要性，不做选择。

## 四、产品或场景设计：先解决哪个问题

常见题干是“设计/优化一款产品”“某场景下如何解决问题”。

- **判断任务**：从具体场景中选择首要问题，提出最小可验证解。
- **核心链**：目标用户和触发场景 → 当前行为/替代方案 → 关键障碍 → 成功标准 → 方案与优先级 → 验证和失败风险。
- **决定性检查**：方案是否对应一个已定义问题，还是把常见功能拼成产品？
- **高价值追问**：
  - “用户现在不用你的方案时如何解决？最痛的一步是什么？”
  - “只能先解决一个问题时，你选哪个，依据是什么？”
  - “不用把完整产品做出来，怎样验证最关键假设？”
- **常见失误**：功能堆砌；用户和场景过宽；指标只写 DAU、留存而不对应核心假设。

## 五、优先级与取舍：用什么标准做决定

常见题干是“去掉一个功能”“体验与商业化如何平衡”“需求如何排序”。

- **判断任务**：在明确目标和约束下比较选项的增量价值、成本与风险。
- **核心链**：决策目标 → 约束 → 备选项的边际影响 → 权重和不可逆风险 → 选择 → 复核条件。
- **决定性检查**：排序标准是否统一；用户规模、需求强度、收益和实现成本是否被混为一层？
- **高价值追问**：
  - “这次排序只允许一个第一目标，它是什么？”
  - “哪项影响是不可逆的，哪项可以后补？”
  - “什么变化会让你调换前两项？”
- **常见失误**：把多个维度各说一遍却不赋权；用“都很重要”回避选择；抽象谈平衡。

## 六、数据异动与归因：从变化到可验证解释

常见题干是“指标突然下降/上涨”“如何证明增长来自优化”。

- **判断任务**：确认异动真实存在，定位主要贡献因子，并设计验证和行动。
- **核心链**：口径/基线/数据质量 → 季节与生命周期 → 横向拆分结构和属性 → 纵向拆漏斗与驱动 → 贡献度 → 假设验证 → 处置。
- **决定性检查**：整体变化来自各组表现变化，还是用户/渠道结构变化？不要忽略辛普森悖论。
- **高价值追问**：
  - “先排除哪类非业务原因？”
  - “这是某一分群自身变差，还是低表现分群占比上升？”
  - “哪个因子贡献最大？用什么对照或实验验证？”
- **常见失误**：一上来穷举几十个原因；只拆维度不算贡献；发现相关性就下因果结论。

## 七、行业研究与市场估算：定义边界比算数更重要

常见题干是“分析某行业”“估算市场规模、收入或用户数”。

- **判断任务**：为具体决策定义市场、建立可解释估算，并识别增长驱动和可获得空间。
- **核心链**：研究目的 → 地域/时间/口径 → 需求基本盘 → 供给与竞争 → 自上而下和自下而上估算 → 交叉验证 → 区间与敏感变量。
- **决定性检查**：注册、活跃、下单、支付、核销、收入和 GMV 等口径是否混用？
- **高价值追问**：
  - “这个数字要支持什么决策，边界怎么定义？”
  - “用另一条独立路径估算，结果是否同量级？”
  - “哪个假设最敏感，变化 20% 会不会推翻结论？”
- **常见失误**：追求精确点估计；背行业数字不说明口径；只算 TAM，不判断 SOM 和能力约束。

## 八、AI 产品判断：从能力变化推演价值与竞争

常见题干是“为什么某产品采取这个 AI 动作”“当基础能力趋同时，产品靠什么
竞争”“AI 会把价值从哪一层迁移到哪一层”。

- **判断任务**：解释 AI 能力变化怎样改变用户行为、产品形态、控制点、成本
  或参与方利益，并判断优势能否积累及何时失效。
- **核心链**：可观察的产品/竞争现象 → 行为、成本或控制权变化 → 价值迁移
  → 稀缺且可积累的能力 → 竞争回应 → 边界与反事实。
- **决定性检查**：答案是在讲 Agent、RAG、评测等怎么做，还是用必要的技术
  事实解释为什么某个产品动作成立、谁因此获益以及优势是否持久？
- **高价值追问**：
  - “如果所有竞争者都能获得同样的模型和工具，你认为优势还剩在哪里？”
  - “这项优势会不会随使用形成复利，还是很快被平台或竞品复制？”
  - “谁掌握任务入口、用户关系和结果责任？这会怎样改变议价权？”
  - “哪一个条件变化会让你的胜负判断反转？”
- **常见失误**：把技术先进等同于产品优势；把使用数据自动视为护城河；
  只看模型能力，不看分发、工作流、信任、成本和平台控制；讨论技术步骤而
  没有产品现象。
- **边界**：若问题只要求设计评测、RAG、Prompt、Agent 架构或实现流程，
  它是 AI 产品专业知识题，不按 PM Sense 训练；完整路由见
  `ai-product-sense.md`。

## 题型化方法卡

训练结束时，方法卡至少保留：

- 本题主判断任务；
- 最有效的第一观察点；
- 用户本轮实际搭建出的核心链；
- 决定结论的变量、权重或约束；
- 本轮出现的典型坏味道；
- 可证伪信号；
- 一道不同产品、同判断任务的迁移题。
