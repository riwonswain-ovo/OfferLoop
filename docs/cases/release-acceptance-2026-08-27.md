## 真实飞书发布门槛

正式同步公开仓和创建 tag 前，仍需在用户授权的飞书环境中完成并记录：

1. 从没有 OfferLoop 配置的新 Agent 会话执行只读预检，确认不会把本地安装误报为 `ready`。
2. 经用户确认后创建或接管三张业务 Base、私有知识库和连续的 `00`–`06` 目录，回读 schema v7
   locator、身份与权限。
3. 验证 7 个 Skill 能读取各自必需材料并把产物写回正确目录；至少覆盖企业清单、求职进展、
   笔面试中心和一份文档产物。
4. 在启用每日进展确认时验证 `22:10 Asia/Shanghai`、唯一所有者、群成员分页保护和重复动作幂等；
   未启用时确认不会要求群聊、所有者或日历配置。
5. 使用升级快照对一个旧工作区预演 `00`–`08` 到 `00`–`06` 的原地迁移，冲突时必须停写；
   经用户确认后才执行实际改名并逐项回读。
6. 验收记录只保留脱敏结果、失败原因和清理状态，不写入 Base URL、token、record ID、邮箱内容或凭证。
