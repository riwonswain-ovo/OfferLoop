# 旧 OfferLoop 工作台退役记录

## 决策

旧 OfferLoop 飞书工作台于 2026-08-17 冻结并退役。线上应用保留历史发布快照并标记为已退役，
不删除应用、数据库或历史数据；仓库保留旧模板源码，仅供审计与新版产品设计参考。

## 退役范围

- 安装器不再提供旧工作台铺设命令。
- 完整部署、离线预检和在线验收不再包含 `workbench` 能力。
- 主分支 CI 不再构建或测试旧工作台模板。
- 旧模板的 materializer 拒绝所有新部署请求。
- `competency-lab` 每日三题改为 Chat 交付，并按用户配置写入知识库，不再写旧工作台数据库。
- 新配置不再登记 `workbench_url`；旧配置中的该键可以继续存在，但不会被读取为就绪条件。

## 明确保留

- 三张业务 Base 及其记录、字段、视图和 workflow。
- 独立的求职进展同步与笔面试提醒应用。
- 每日群卡片、求职进展 schema v6 和笔面试中心单表结构。
- 旧工作台源码、历史文档和线上发布快照。

## 新版边界

新版工作台必须使用新的产品合同、信息架构、权限模型和独立妙搭应用，不得直接恢复旧模板发布，
也不得让新版前端成为三张 Base 之外的第二业务真源。

## 验收

- 完整仓库测试通过。
- 活动的进展同步模板完成测试、类型检查与构建。
- 安装与完整部署输出不再出现工作台资源或阶段。
- 旧工作台退役不改变当前同步/提醒应用。
