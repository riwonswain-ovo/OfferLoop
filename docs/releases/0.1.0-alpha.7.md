# OfferLoop 0.1.0-alpha.7

本版本明确区分必需的飞书知识库和可选的飞书工作台。

## 架构变化

- OfferLoop 完成线上初始化后必须有一个默认私有知识库。
- 企业清单、求职进展和笔面试中心作为唯一 Base 对象纳入 `01｜核心求职数据`，不复制数据。
- 当前简历和五类训练 Markdown 产物统一保存在固定知识库目录。
- `offerloop-workspace` 只管理知识库、Base 节点、首页和训练产物。
- 新增可选 `offerloop-workbench`，独立负责妙搭模板、OAuth、发布和浏览器验收。
- 工作台未选择、未部署或失败时，不影响任何业务 Skill、日历、知识库或训练产物。

## 配置与兼容

- 新增 `workspace_core_data_node_token`，用于定位知识库中的核心数据目录。
- `workbench_url` 不再属于 workspace 就绪条件，只在工作台验收成功后登记。
- 已登记的旧训练目录 locator 继续有效，不自动移动、重命名或删除线上节点。
- 安装包现在包含十个 Skill。
