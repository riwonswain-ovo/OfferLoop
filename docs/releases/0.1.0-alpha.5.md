# OfferLoop 0.1.0-alpha.5 发布说明

状态：本地预发布候选。日期：2026-07-24。尚未推送 GitHub。

本次版本在原有四个基础 Skill 上新增五个互联网求职训练 Skill、一个面试题库 Skill 和一个
知识输入 Skill，共计十一个 Skill。训练产物统一沉淀到用户私有飞书知识库，知识输入能力新增
独立的信息源、阅读计划和摘要契约。

## 新增 Skill

- `resume-deepthink`：追问式深挖真实经历，输出简历表达和面试素材。
- `pm-sense`：用户先独立回答，再点评、追问、研究并形成 1 分钟/3 分钟答案。
- `interview-prep`：结合面试事件、JD、实际投递简历和长期素材生成准备文档。
- `mock-lab`：一题一答模拟，过程中不反馈，结束后统一生成逐题报告。
- `talk-review`：根据 ASR 或转写稿还原问答并生成真实面试复盘。
- `interview-question-bank`：统一管理待学习和已学会题目，接收训练与复盘确认后的候选题。
- `knowledge-digest`：盘点知识库、制定阅读计划，并增量追踪用户感兴趣的新闻来源。

结构化/半结构化央国企面试专项不在本版本范围。`mock-interview` 只作为设计参考，不是运行时
依赖；`pm-sense` 不生成小红书排版、图片、HTML 或 ZIP。

## 飞书产物与配置

- 公共配置升级为 schema v4，新增 `artifact_storage`，保留 schema v2 的全部既有值。
- 五个 Skill 运行前从飞书读取材料，完成或明确提前结束后保存 Markdown Docx/Wiki 文档。
- 每次产物包含全局唯一 `run_id`；重试按确定性标题去重。
- 文件夹 locator 与长期主档 locator 分离，目录按首次使用懒创建。
- 经历和产品主档只合并用户确认内容；冲突必须展示双方值和来源。

## 面试事件联动

- `recruiting-reminder` 新增离线 `event_lookup.py` 契约，统一候选匹配和主子表 ID 解析。
- 面试准备和复盘按精确 record ID 幂等回填。
- 岗位、环节或时间不匹配时不退回公司级猜测。
- 任一旧文档链接冲突时不生成写入操作；笔试事件拒绝回填面试文档。

## 安装与入口

- 安装器、冷安装验收和 preflight 从四个 Skill 更新为十一个 Skill。
- 首次安装输出按基础、训练和知识输入三组介绍十一个 Skill、使用示例、常用闭环、隐私边界和下一条指令；
  JSON 安装结果提供相同的结构化 `welcome`，重复安装不反复显示。
- `offerloop-setup` 新增十一 Skill 首次欢迎、`coaching` / `knowledge` 能力和显式 schema v4 迁移。
- 知识库首页和工作台保留完整十一 Skill 能力地图；工作台按三组折叠展示。
